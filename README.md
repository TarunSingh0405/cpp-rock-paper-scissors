# 🎮 Rock Paper Scissors Game | C++

A beginner-friendly, console-based Rock Paper Scissors game developed using C++. This project is part of my C++ programming journey, where I am learning programming fundamentals through practical projects.

## 📌 About the Project

This project allows a player to compete against the computer in a classic Rock Paper Scissors game.

The player selects Rock, Paper, or Scissors, while the computer randomly generates its choice. The program compares both choices and determines whether the player wins, loses, or gets a tie.

## ✨ Features

- Player vs Computer gameplay
- Random computer choice generation
- Interactive console-based input
- Automatic winner determination
- Three possible outcomes: Win, Lose, and Tie

## 🛠️ Technologies Used

- **Language:** C++
- **Compiler:** GCC
- **Code Editor:** Visual Studio Code

## 📚 C++ Concepts Used

Through this project, I practised:

- Functions and Function Calls
- Function Declarations and Return Values
- Character Data Types
- Conditional Statements (`if-else`)
- Switch Statements
- User Input and Output
- Random Number Generation (`rand()` and `srand()`)
- Time Library (`<ctime>`)

## 🎯 Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both player and computer select the same option, it's a tie.

## ▶️ How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/TarunSingh0405/cpp-rock-paper-scissors.git
```

**2. Open the project folder**

```bash
cd cpp-rock-paper-scissors
```

**3. Compile the program**

```bash
g++ RockPaperScissor.cpp -o RockPaperScissor
```

**4. Run the program on Windows**

```bash
.\RockPaperScissor.exe
```

## 🎮 How to Play

When the program starts:

- Enter `r` for Rock.
- Enter `p` for Paper.
- Enter `s` for Scissors.

The computer will randomly select its choice, and the program will display the result.
